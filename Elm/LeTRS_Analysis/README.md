## Guide to python notebooks

1. **LeTRS_sgEN.ipynb**: Visualization of LeTRS results on synthetic sgENERATE data
2. **SOS_Poster_Vis.ipynb**: Used to make visualizationsf or SOS & ISMB posters & first year presentation. Contains heatmaps w/ precision and recall
3. **combined_LeTRS_analysis.ipynb**: Visualizations showing LeTRS results across runs. Has all data, requires aggregated data from combine_LeTRS_output.py
4. **metadata_summary.ipynb** Visualizing metadata pulled from pull_data.py
